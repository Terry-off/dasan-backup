팝업 관리

메인 화면 등에 띄울 팝업입니다. 노출 기간을 정하면 그 기간에만 자동으로 표시되고, 기간이 지나면 자동으로 사라집니다.

사진 · 텍스트 수정

아래 미리보기에서 바꾸고 싶은 글자를 클릭하세요. 편집창이 열립니다.

연결 설정

수정 내용을 GitHub 저장소에 바로 반영하기 위한 설정입니다. 이 정보는 지금 사용 중인 브라우저에만 저장되며 외부로 전송되지 않습니다.

토큰 만드는 방법
  1. GitHub 로그인 → 우측 상단 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token → Repository access 에서 이 백업 저장소만 선택
  4. Permissions → Repository permissions → Contents 를 Read and write 로 변경
  5. 생성된 토큰을 복사해 위 칸에 붙여넣기

사용 방법

  1. 연결 설정 탭에서 GitHub 정보와 토큰을 넣고 연결 확인을 누릅니다. (최초 1회만)
  2. 팝업 관리에서 팝업을 등록·삭제하고 노출 기간을 지정합니다.
  3. 사진 · 텍스트 수정에서 페이지를 고르고, 바꿀 글자나 사진을 클릭해 수정합니다.
  4. 오른쪽 위 저장하고 사이트에 반영을 누릅니다.
  5. 약 1분 뒤 실제 사이트에 반영됩니다. (GitHub Pages 배포 시간)
참고
  • 수정 내용은 원본 HTML을 건드리지 않고 data/site-config.json 에만 저장됩니다. 언제든 되돌릴 수 있습니다.
  • 이 관리자 페이지 주소를 아는 사람이 접속할 수는 있지만, 토큰이 없으면 아무것도 변경할 수 없습니다.
  • 공용 PC에서 작업했다면 연결 설정 → 토큰 지우기를 눌러 주세요.
